# Smart Integrity City

เว็บแอปประกอบเกมกระดานเพื่อเสริมสร้างคุณลักษณะ 5 ประการ (คิด วินัย ซื่อสัตย์ พอเพียง จิตสาธารณะ) ครอบคลุม 4 ระยะ: เตรียมเกม → เล่นเกม → จบเกม → หลังเกม พร้อมระบบหลังบ้านสำหรับครู

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้องติดตั้งอะไร) หรือเปิดเป็น GitHub Pages

## ฟีเจอร์ตามเอกสาร

- หน้าแรกคือหน้าเข้าสู่ระบบ (อีเมล + รหัสผ่าน) และมีปุ่มสมัครสมาชิก: ถ้าใส่รหัสครูในช่องรหัสผ่านจะเข้าระบบครู นอกนั้นเข้าเป็นผู้เล่นปกติด้วยบัญชีที่สมัครไว้
- หลังเข้าสู่ระบบมี 2 ส่วน: สร้างห้อง (เลือกสื่อการสอน → ลงทะเบียนผู้เล่น 6 คนตามอาชีพ) และค้นหาห้องเรียนด้วยรหัสห้องเพื่อทำภารกิจ/สอบหลังเกม
- Pre-Test ข้อสอบปลายเปิด 10 ข้อ (หมวดละ 2 ข้อ: คิด วินัย ซื่อสัตย์ พอเพียง จิตสาธารณะ) ข้อละ 3 คะแนน เต็ม 30 (เต็ม 6 ต่อคุณลักษณะ) แสดงทีละข้อ อ่านโจทย์แล้วกด "เริ่มทำ" มีเวลา 30 วินาทีต่อข้อ และแสดงคะแนนข้อนั้นทันที
- ตั้งเวลาเล่น (ขั้นต่ำ 20 นาที) และดัชนีเมืองเริ่มต้น 100
- ช่องภารกิจพลเมือง / คุณลักษณะ / ท้าทายจริยธรรม: เลือกผู้เล่นก่อน (ภารกิจพลเมืองเลือกอาชีพของช่องที่ตก, คุณลักษณะเลือกหมวดแล้วสุ่มโจทย์) → แสดงโจทย์ → กด "เริ่มทำ" แล้วนับเวลา 30 วินาที (หมดเวลาส่งคำตอบอัตโนมัติ)
- ระบบตรวจสอบ (การ์ดหนี, คะแนน 0–5, ยึดเป้าหมาย; ถ้ายังไม่มีขั้นสำเร็จหัก −10 แทน)
- แผงปุ่มบวก/ลบคะแนนด้วยตนเอง: ต่อผู้เล่นปรับดัชนีชีวิต แต้มร่วมมือ ดัชนีเมือง และปรับดัชนีเมืองทั้งเมือง (กดครั้งละ 1 แต้ม) ใช้กับการ์ดข่าวสารหรือการ์ดหนีการตรวจสอบบนกระดาน
- จบเกม: เมืองล่มสลาย (ดัชนีเมือง 0 → แพ้ร่วม) หรือหมดเวลา (จัดอันดับ ชีวิต+ร่วมมือ → ขั้นภารกิจ → ดัชนีชีวิต)
- แดชบอร์ดกราฟเรดาร์ ก่อนเล่น vs ผลในเกม
- หลังเกม: ภารกิจชีวิตจริง 5 คุณลักษณะ (ภาพ+คำอธิบาย, ภายใน 3 วัน), Post-Test, เกียรติบัตร (พิมพ์/บันทึกเป็น PDF)
- หลังบ้านครู: แก้ชุดสื่อการสอน (JSON), ตารางแต้มกลาง, ตรวจภาพภารกิจชีวิตจริง, ส่งออกรายงาน (CSV เปิดด้วย Excel)

ช่องผ่านจุดเริ่มต้นและขั้นตอนเลือกผู้เล่นบนกระดาน เว็บไม่รับผิดชอบตามที่กำหนด

## รหัสครู

ค่าเริ่มต้นคือ `TEACHER2026` **ควรเปลี่ยนก่อนใช้งานจริง** รหัสถูกเก็บเป็นค่าแฮช SHA-256 ใน `data.js` (`TEACHER_CODE_HASHES`) สร้างค่าแฮชใหม่ด้วย:

```
node -e "console.log(require('crypto').createHash('sha256').update('รหัสใหม่').digest('hex'))"
```

หมายเหตุ: เป็นการตรวจฝั่งเบราว์เซอร์ ผู้ที่เปิดดูโค้ดสามารถเลี่ยงได้ ใช้เพื่อแยกหน้าจอเท่านั้น ไม่ใช่ระบบความปลอดภัยจริง (ต้องมี backend)

## ข้อจำกัดของเวอร์ชันนี้ (ต้องรู้)

- **ข้อมูลเก็บใน localStorage ของเบราว์เซอร์** ไม่มีเซิร์ฟเวอร์ จึงใช้ข้อมูลร่วมกันข้ามเครื่องไม่ได้ และบัญชีผู้ใช้เป็นเพียงเดโม ถ้าจะใช้จริงหลายเครื่อง (เช่น ผู้เล่นทำภารกิจหลังเกมจากมือถือตัวเอง) ต้องเพิ่ม backend เช่น Supabase/Firebase
- **ตัวตรวจคำตอบเป็นแบบคำสำคัญ ไม่ใช่ AI จริง** — ข้อสอบ Pre/Post แต่ละข้อมีกลุ่มคำสำคัญ 3 กลุ่ม (ดูว่าคำตอบตรงกับแนวคำตอบกี่ประเด็น ตรงกลุ่มละ 1 คะแนน เต็ม 3 ไม่พิจารณาความยาว คำตอบสั้นแต่ตรงประเด็นก็ได้คะแนน) แนวคำตอบของครูอยู่ในช่อง `ans` ของแต่ละข้อ (ไม่แสดงให้ผู้เล่นเห็น) ตัวตรวจนี้ให้คะแนนผิดพลาดได้ทั้งสองทาง (เช่น คำตอบดีแต่ใช้คำต่าง หรือใส่คำสำคัญเรียงกันโดยไม่มีความหมาย) จึงควรใช้เป็นคะแนนเบื้องต้น และให้ผู้ประเมินตรวจซ้ำตามแนวทางในเอกสารข้อสอบ ส่วนภารกิจในเกมผู้ควบคุมเกมต้องยืนยันผลก่อนบันทึกแต้มทุกครั้ง หากต้องการเชื่อมโมเดล AI ให้กำหนดฟังก์ชัน `window.AI_EVALUATOR(text, lesson, kind, question)` โดย `kind` เป็น `'pretest'`/`'posttest'` ให้คืน `{score: 0-3}` ส่วนภารกิจในเกมคืน `{verdict: 'pass'|'fail'|'corrupt', auditScore: 0-5}` (ควรเรียกผ่าน backend ของคุณเพื่อไม่เปิดเผยคีย์)
- **ตรวจ 2 ชั้น (ในเบราว์เซอร์ ฟรี ไม่ใช้ AI)**: (1) ความใกล้เคียงกับแนวคำตอบเป็น % (ตัดคำภาษาไทยด้วย `Intl.Segmenter` ตัดคำเชื่อม แล้วดูว่าสาระของแนวคำตอบปรากฏในคำตอบกี่ %, ไม่คิดความยาว) แปลงเป็น 0–3 ตามเกณฑ์ที่ครูปรับได้ (ค่าเริ่มต้น ≥15% = 1, ≥25% = 2, ≥35% = 3) (2) กลุ่มคำสำคัญ 3 กลุ่ม ใช้คะแนนที่สูงกว่าของสองชั้น และให้ 0 ถ้าพบถ้อยคำกลับด้านที่แนวคำตอบไม่มี (เช่น "ไม่ต้องบอกใคร", "ไม่ใช่เรื่องของเรา") ครูเพิ่ม "คำตอบอื่นที่รับได้" ต่อข้อ และลองตรวจในแท็บ "ทดลองตรวจ/แนวคำตอบ" ได้ ไฟล์ `test/exam_samples.json` + `node test/calib.js` ใช้วัดความสอดคล้องกับป้ายคะแนนตัวอย่าง (ป้ายเขียนโดยผู้พัฒนา ไม่ใช่ครูจริง ควรให้ครูตรวจชุดตัวอย่างของตนแล้วปรับเกณฑ์) ระบบยังตรวจความหมายจริง ๆ ไม่ได้ จึงเป็นคะแนนเบื้องต้น
- **ดูสด (ครูดูว่าผู้เรียนพิมพ์อะไรอยู่)**: แท็บ "ดูสด" ในหลังบ้านครู แสดงผู้เรียน ห้อง หน้าจอ/ข้อ โจทย์ ข้อความที่กำลังพิมพ์ และเวลาที่เหลือ อัปเดตทุก ~2 วินาที (ถ้าไม่มีสัญญาณเกิน 2 นาทีถือว่าออฟไลน์) **ข้ามเครื่องต้องมีฐานข้อมูลออนไลน์**: สร้าง Firebase Realtime Database (โหมดทดสอบหรือกำหนด rules ให้เขียน/อ่านเฉพาะพาธ `sic/live`) แล้วใส่ URL ใน `config.js` ที่ `liveDb` (ไฟล์นี้ใช้กับทุกเครื่อง) ถ้าเว้นว่าง จะใช้ได้เฉพาะเบราว์เซอร์เดียวกัน ซึ่งใช้งานจริงยาก เพราะการเข้าสู่ระบบเก็บใน localStorage ร่วมกัน (ทดสอบกับเซิร์ฟเวอร์จำลองแบบ REST ของ Firebase แล้ว ยังไม่ได้ทดสอบกับ Firebase จริง) ข้อควรระวัง: ข้อความที่พิมพ์จะถูกส่งไปเก็บในฐานข้อมูลของคุณ และถ้าตั้ง rules แบบเปิด ใครที่รู้ URL อ่านได้ ควรแจ้งนักเรียน/ผู้ปกครองและอย่าให้นักเรียนพิมพ์ข้อมูลส่วนตัว
- Post-Test ใช้ข้อสอบปลายเปิดและเกณฑ์เดียวกับ Pre-Test (10 ข้อ ข้อละ 3 คะแนน เต็ม 30) หลังทำเสร็จแสดงตารางเทียบ Pre/Post รายคุณลักษณะ — เอกสารข้อสอบเขียนเกณฑ์ "เต็ม 2 คะแนนต่อข้อ" แต่ตารางสรุปเต็ม 6 ต่อด้าน/30 รวม และมีช่อง "/ 3" ต่อข้อ จึงใช้ข้อละ 3 คะแนนตามเกณฑ์ (0 ปรับปรุง / 1 พอใช้ / 2 ดี / 3 ดีมาก)
- เกณฑ์ผ่านเกียรติบัตร: Post-Test 30 คะแนน + ภารกิจชีวิตจริงที่ครูอนุมัติ 5 คะแนน = 35 ค่าเริ่มต้นผ่านที่ 21 (60%) ครูปรับได้ในหลังบ้าน
- ผลตรวจสอบ 1–3 คะแนน เอกสารระบุเพียง "ทำตามกติกา" จึงให้เลือก "เดินถอยหลัง" หรือหักแต้มตามค่าที่ครูตั้งในตาราง
- ชุดสื่อการสอนที่ให้มาเป็นตัวอย่าง ครูควรแก้ไขให้เหมาะกับบทเรียนจริง

## โครงสร้างไฟล์

- `index.html`, `styles.css` — หน้าเว็บ
- `data.js` — ตัวละคร คุณลักษณะ ตารางแต้ม และชุดสื่อตัวอย่าง
- `core.js` — ตรรกะเกม/คะแนน (ทดสอบได้ด้วย node: `node test.js`)
- `app.js` — ส่วนติดต่อผู้ใช้
- `live.js`, `config.js` — ระบบดูสดและค่าตั้ง (liveDb)
- `test/` — ตัวอย่างคำตอบ + สคริปต์วัดผล (`calib.js`) และทดสอบดูสด (`e2e_live.js` ต้องมี Playwright)
- `test.js` — ทดสอบตรรกะหลัก
