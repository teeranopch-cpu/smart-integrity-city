# Smart Integrity City

เว็บแอปประกอบเกมกระดานเพื่อเสริมสร้างคุณลักษณะ 5 ประการ (คิด วินัย ซื่อสัตย์ พอเพียง จิตสาธารณะ) ครอบคลุม 4 ระยะ: เตรียมเกม → เล่นเกม → จบเกม → หลังเกม พร้อมระบบหลังบ้านสำหรับครู

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้องติดตั้งอะไร) หรือเปิดเป็น GitHub Pages

## ฟีเจอร์ตามเอกสาร

- หน้าแรกคือหน้าเข้าสู่ระบบ (อีเมล + รหัสผ่าน) และมีปุ่มสมัครสมาชิก: ถ้าใส่รหัสครูในช่องรหัสผ่านจะเข้าระบบครู นอกนั้นเข้าเป็นผู้เล่นปกติด้วยบัญชีที่สมัครไว้
- หลังเข้าสู่ระบบมี 2 ส่วน: สร้างห้อง (เลือกสื่อการสอน → ลงทะเบียนผู้เล่น 6 คนตามอาชีพ) และค้นหาห้องเรียนด้วยรหัสห้องเพื่อทำภารกิจ/สอบหลังเกม
- Pre-Test 5 ข้อ เก็บค่าฐาน (Baseline) รายคุณลักษณะ
- ตั้งเวลาเล่น (ขั้นต่ำ 20 นาที) และดัชนีเมืองเริ่มต้น 100
- ช่องภารกิจพลเมือง / คุณลักษณะ / ท้าทายจริยธรรม: เลือกผู้เล่นก่อน (ภารกิจพลเมืองเลือกอาชีพของช่องที่ตก, คุณลักษณะเลือกหมวดแล้วสุ่มโจทย์) → แสดงโจทย์ → กด "เริ่มทำ" แล้วนับเวลา 30 วินาที (หมดเวลาส่งคำตอบอัตโนมัติ)
- ระบบตรวจสอบ (การ์ดหนี, คะแนน 0–5, ยึดเป้าหมาย; ถ้ายังไม่มีขั้นสำเร็จหัก −10 แทน)
- แผงปุ่มบวก/ลบคะแนนด้วยตนเอง: ต่อผู้เล่นปรับดัชนีชีวิต แต้มร่วมมือ ดัชนีเมือง และปรับดัชนีเมืองทั้งเมือง (กดครั้งละ 1 แต้ม) ใช้กับการ์ดข่าวสารหรือการ์ดหนีการตรวจสอบบนกระดาน
- จบเกม: เมืองล่มสลาย (ดัชนีเมือง 0 → แพ้ร่วม) หรือหมดเวลา (จัดอันดับ ชีวิต+ร่วมมือ → ขั้นภารกิจ → ดัชนีชีวิต)
- แดชบอร์ดกราฟเรดาร์ ก่อนเล่น vs ผลในเกม
- หลังเกม: ภารกิจชีวิตจริง 5 คุณลักษณะ (ภาพ+คำอธิบาย, ภายใน 3 วัน), Post-Test, เกียรติบัตร (พิมพ์/บันทึกเป็น PDF)
- หลังบ้านครู: แก้ชุดสื่อการสอน (JSON), ตารางแต้มกลาง, ตรวจภาพภารกิจชีวิตจริง, ส่งออกรายงาน (CSV เปิดด้วย Excel)

ช่องผ่านจุดเริ่มต้นและขั้นตอนเลือกผู้เล่นบนกระดาน เว็บไม่รับผิดชอบตามที่กำหนด

## รหัสครู

ค่าเริ่มต้นคือ `TEACHER2026` **ควรเปลี่ยนก่อนใช้งานจริง** รหัสถูกเก็บเป็นค่าแฮช SHA-256 ใน `data.js` (`TEACHER_CODE_HASHES`) สร้างค่าแฮชใหม่ด้วย:

```
node -e "console.log(require('crypto').createHash('sha256').update('รหัสใหม่').digest('hex'))"
```

หมายเหตุ: เป็นการตรวจฝั่งเบราว์เซอร์ ผู้ที่เปิดดูโค้ดสามารถเลี่ยงได้ ใช้เพื่อแยกหน้าจอเท่านั้น ไม่ใช่ระบบความปลอดภัยจริง (ต้องมี backend)

## ข้อจำกัดของเวอร์ชันนี้ (ต้องรู้)

- **ข้อมูลเก็บใน localStorage ของเบราว์เซอร์** ไม่มีเซิร์ฟเวอร์ จึงใช้ข้อมูลร่วมกันข้ามเครื่องไม่ได้ และบัญชีผู้ใช้เป็นเพียงเดโม ถ้าจะใช้จริงหลายเครื่อง (เช่น ผู้เล่นทำภารกิจหลังเกมจากมือถือตัวเอง) ต้องเพิ่ม backend เช่น Supabase/Firebase
- **AI ตรวจคำตอบ** ตอนนี้ใช้ตัวประเมินเบื้องต้นแบบคำสำคัญ (ครูแก้คำสำคัญได้ในสื่อการสอน) และให้ผู้ควบคุมเกมยืนยันผลก่อนบันทึกแต้มทุกครั้ง หากต้องการเชื่อมโมเดล AI ให้กำหนดฟังก์ชัน `window.AI_EVALUATOR(text, lesson, kind)` ที่คืนค่า `{verdict: 'pass'|'fail'|'corrupt', auditScore: 0-5}` (ควรเรียกผ่าน backend ของคุณเพื่อไม่เปิดเผยคีย์)
- เกณฑ์ผ่านเกียรติบัตร: Post-Test 5 คะแนน + ภารกิจชีวิตจริงที่ครูอนุมัติ 5 คะแนน = 10 (ค่าเริ่มต้นผ่านที่ 9, ครูปรับได้)
- ผลตรวจสอบ 1–3 คะแนน เอกสารระบุเพียง "ทำตามกติกา" จึงให้เลือก "เดินถอยหลัง" หรือหักแต้มตามค่าที่ครูตั้งในตาราง
- ชุดสื่อการสอนที่ให้มาเป็นตัวอย่าง ครูควรแก้ไขให้เหมาะกับบทเรียนจริง

## โครงสร้างไฟล์

- `index.html`, `styles.css` — หน้าเว็บ
- `data.js` — ตัวละคร คุณลักษณะ ตารางแต้ม และชุดสื่อตัวอย่าง
- `core.js` — ตรรกะเกม/คะแนน (ทดสอบได้ด้วย node: `node test.js`)
- `app.js` — ส่วนติดต่อผู้ใช้
- `test.js` — ทดสอบตรรกะหลัก
